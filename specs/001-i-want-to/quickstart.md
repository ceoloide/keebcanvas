# Quickstart Guide

This guide provides instructions for setting up and running the application.

## Setup

1.  Install dependencies:

    ```bash
    npm install
    ```

2.  Run the development server:

    ```bash
    npm run dev
    ```

## Validation

1.  Open the application in your browser at `http://localhost:3000`.
2.  Click the "Download YAML" button.
3.  Verify that a file named `layout.yaml` is downloaded.
4.  Open the `layout.yaml` file and verify that it contains the following basic structure:

    ```yaml
    points:
      zones: {}
    ```
